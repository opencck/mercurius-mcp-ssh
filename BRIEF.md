# mercurius-mcp-ssh

## Назначение и границы

MCP-сервер по stdio для одного SSH-сервера: команда, файл через `cat`, TCP-проба. Это SSH-модуль Меркурия
(сабмодуль `mcp/ssh`): каждый сервер — запись `.mcp.json` со своим процессом. Сервер ничего не решает о том, что
команде можно: классификатор, правила «никогда без владельца», карточки и журнал — в ядре Меркурия вокруг его
инструментов. SQL идёт через `run`: ядро собирает команду `psql` или `mysql` и подаёт запрос и пароль в stdin, тот
же путь, что любая команда (журнал, маршрут, ключ хоста); отдельного туннеля к базе нет.

## Устройство

- `Options` — хост, порт, логин, файл ключа, закреплённый ключ хоста, промежуточный сервер (`--jump-*`) из
  аргументов; пароль, ключ текстом, пароль ключа, маршрут и вход промежуточного сервера — из окружения
  (`SSH_PASSWORD`, `SSH_PRIVATE_KEY`, `SSH_KEY_PASSPHRASE`, `SSH_PROXY`, `SSH_JUMP_PASSWORD`, `SSH_JUMP_PRIVATE_KEY`).
  Без `--host` сервер запускается и отвечает на каждый вызов, чего не хватает: так его пробует установка.
- Маршрут — `RouteFactory::fromUri` пакета `mercurius-connectors` (HTTP CONNECT, SOCKS5, VLESS); через
  промежуточный сервер — канал `direct-tcpip` его соединения (`TunnelConnector`), маршрут тогда ведёт к нему.
- `Sudo` — команда из одной части с `sudo` в начале получает пароль входа: `sudo -S -p '' sh -c '<команда> <
  /dev/null'`, пароль первой строкой stdin; из нескольких частей — не получает. Пароль, его base64 и hex
  заменяются в выводе на `***`.
- `SshRemote` — одно соединение `amphp/ssh`, открывается первым вызовом и держится; умершее открывается заново один
  раз. Команда — `timeout --kill-after=5 <сек> sh -c …`; вывод — по 64 КБ каждого потока.
- `Server` — JSON-RPC по строкам: `initialize`, `tools/list`, `tools/call`, `ping`. Ответ `run` — текст и
  `structuredContent` (`exit`, `stdout`, `stderr`, `cut`): ядро читает поля, а не текст.
- `mercurius.mcp.json` — план установки в Меркурий: `composer install --no-dev` и запись `php ${INSTALL_DIR}/bin/ssh-mcp`.

## Решения

- **Ключ хоста только закреплённый.** Без `--host-key` или при другом ключе соединение обрывается до входа, вызов
  отвечает `UNKNOWN_HOST_KEY <отпечаток> new|changed`: закрепляет ключ владелец через ядро.
- **Секреты — в окружении процесса**, не в аргументах: аргументы видны в списке процессов.
- **Файлы через `cat`**, как в ядре Меркурия: без SFTP.
- **Ключ входа текстом — в файле в памяти** только на время входа: `amphp/ssh` читает ключ лишь из файла.
- **Неизвестный ключ промежуточного сервера** называется словом `jump` в конце ответа: его закрепляют отдельно.
